---
name: Multi-Toolbox privacy boundary
description: Product requirements for local processing, cost, and external services.
---

The user wants calculations and file processing to stay in the browser wherever practical. Do not add paid services, paid APIs, or third-party file uploads without the user's explicit permission.

**Why:** the user explicitly prioritized file privacy and a free starting point.

**How to apply:** keep image and PDF processing client-side by default; explain any service or cost requirement before proposing a change.
